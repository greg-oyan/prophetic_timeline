# The Prophetic Timeline

**An immersive visual journey through Biblical prophetic history — 42 events from Creation to the New Creation.**

An interactive, cinematic timeline tracing the prophetic arc of Scripture: from Genesis through the Exile, the fall of the Temple in 70 AD, and forward to the Second Coming. Each event carries scripture references and its prophetic connections to other events, so the timeline reads as a web of fulfillment rather than a list of dates.

## Design intent

- **Cinematic, not academic** — Cormorant Garamond typography, dark immersive presentation, built to be *experienced* rather than skimmed
- **Connections over chronology** — events link to the prophecies they fulfill and the ones they set up
- **Text-first** — every claim is anchored to chapter-and-verse references rather than paraphrase

## Stack

React (Vite), single-page app, deployable as a static site.

```bash
npm install
npm run dev      # local development
npm run build    # production build to ./dist
```
